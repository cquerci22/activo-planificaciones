# Activo Planificaciones — versión online

Esta versión está conectada a Supabase y lista para GitHub Pages.

## Publicación
1. Creá un repositorio público en GitHub llamado `activo-planificaciones`.
2. Subí los tres archivos: `index.html`, `style.css` y `app.js`.
3. Entrá en `Settings` → `Pages`.
4. En `Build and deployment`, elegí `Deploy from a branch`.
5. Seleccioná `main` y `/ (root)`.
6. Guardá y esperá a que GitHub muestre el enlace.

## Panel del profesor
Usá el correo creado en Supabase y tu contraseña personal.

## Seguridad
La app usa la Publishable Key. No agregues una Secret Key ni `service_role`.
